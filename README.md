## Homelab

A Proxmox environment I use as a proving ground:

- A three-node Proxmox HA cluster for failover, quorum and recovery drills (power-pull tests included)
- Infrastructure as code with Terraform and Ansible, with the config tracked in a self-hosted Git server
- Self-hosted services behind Tailscale, with a Synology NAS and a dedicated backup server
- Backup and restore rehearsed, not assumed
